# 🎨 Logo Information - logo2.png

## 📁 **Required File**

The website uses a custom logo image in the header navigation.

---

## 📍 **File Location**

Place your logo file here:
```
assets/images/logo2.png
```

**File Name:** `logo2.png` (exactly, case-sensitive)

---

## 🖼️ **Logo Specifications**

### **Recommended Specs:**
- **Format:** PNG (with transparent background)
- **Size:** 200x200 pixels (or square ratio)
- **File Size:** < 50KB (optimized)
- **Background:** Transparent
- **Colors:** Gold/Yellow tones (to match theme)

### **Display Size:**
- **Width:** 50px
- **Height:** 50px
- **Position:** Header navigation (left side)

---

## 🎨 **Design Guidelines**

### **What Works Best:**
✅ Om (ॐ) symbol  
✅ Temple silhouette  
✅ Trishul (त्रिशूल)  
✅ Lotus flower  
✅ Mandala design  
✅ Gold/Golden color scheme  

### **Avoid:**
❌ Complex detailed images (too small)  
❌ Text-heavy logos (unreadable at 50px)  
❌ Dark logos on dark background  
❌ Multiple colors (keep it simple)

## 📥 **If You Don't Have logo2.png Yet**

### **Option 1: Create Your Own**
Use design tools like:
- Canva (free, easy)
- Photoshop
- Illustrator
- GIMP (free)

**Quick Steps:**
1. Create 200x200px canvas
2. Add Om symbol or temple icon
3. Use gold/yellow colors
4. Export as PNG with transparent background
5. Save as `logo2.png`

### **Option 2: Use Free Icons**
Download from:
- **Flaticon:** flaticon.com (search "om symbol", "temple")
- **Freepik:** freepik.com
- **Icons8:** icons8.com
- **The Noun Project:** thenounproject.com

**Search Terms:**
- "om symbol png"
- "hindu temple icon"
- "trishul icon"
- "lotus icon"
- "mandala icon"

### **Option 3: Temporary Fallback**
If you don't have the logo yet, the website will show:
- A broken image icon
- Or you can revert to emoji (🕉️)

**To revert to emoji temporarily:**
Replace in all HTML files:
```html
<!-- Current (uses image): -->
<div class="logo-icon">
    <img src="assets/images/logo2.png" alt="Temple Logo">
</div>

<!-- Change to (uses emoji): -->
<div class="logo-icon">🕉️</div>
```

## 🆘 **Troubleshooting**

### **Logo not showing?**
✓ Check file path: `assets/images/logo2.png`  
✓ Verify file name (case-sensitive)  
✓ Check file format (.png not .jpg)  
✓ Clear browser cache (Ctrl+F5)  

### **Logo looks blurry?**
✓ Use larger source image (200x200px minimum)  
✓ Save as PNG (not JPG)  
✓ Don't stretch small images  

### **Logo too big/small?**
✓ Image should be 200x200px  
✓ Display size is set to 50x50px in CSS  
✓ Use `object-fit: contain` (already set)

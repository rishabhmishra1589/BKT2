## 🆘 **Troubleshooting**

### **Images not showing?**
✓ Check internet connection (images load from Unsplash CDN)  
✓ Clear browser cache (Ctrl+F5 or Cmd+Shift+R)  
✓ Check browser console for errors (F12)

### **Menu not working on mobile?**
✓ JavaScript file (`main.js`) is loading  
✓ Check browser console for errors (F12)  
✓ Clear browser cache

### **Animations not working?**
✓ Scroll down the page (animations trigger on scroll)  
✓ Check JavaScript is enabled  
✓ Try different browser

## 🎨 **Quick Customizations**

### **Change Main Color:**
Open `assets/css/style.css`, find line ~20:
```css
--saffron: #FF9933;  /* Change this color */
```

### **Add Your Logo:**
Replace emoji in header (line ~100 in HTML files):
```html
<div class="logo-icon">🕉️</div>  <!-- Replace emoji or add image -->
```

### **Change Hero Text:**
Edit `index.html` around line ~200:
```html
<h1 class="hero-title">Your Custom Title</h1>
```
